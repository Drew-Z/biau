# 公共界面中英文：共享框架与语言偏好

## Goal

按用户“分阶段补齐中英文，先公共界面再内容”的决定，先让跨路由共享界面响应语言选择，并在刷新后保留访客选择。

## Requirements

- 中文为首次访问及无效偏好的默认语言；访客可随时切换中英文。
- 选择跨路由、前进后退和刷新保留，不能影响主题或筛选 URL。
- 桌面/移动导航的可见文案与辅助名称、页脚、路由载入及 404 恢复界面随语言更新。
- 未翻译的页面与项目/文章内容保持中文语义；不能把中文正文标为英文，也不能生成并不存在的英文内容或 SEO 地址。
- 存储不可用时仍能渲染和切换。保持导航焦点、三主题布局与页面返回路径。
- 此项是公共界面的第一批。目录、详情、状态、AI 日报与助手控件由后续子任务覆盖，内容翻译随后单独评估。
- 遵守父循环本地提交边界，禁止 push、部署、签名、生产模型调用、公开内容发布、启用 Feed/Cron 和改动保护状态快照。

## Acceptance Criteria

- [x] 中英文共享界面及辅助名称一致，320/390/430/1440px、三主题无新增重叠或水平溢出。
- [x] 语言在 SPA 路由、历史、硬刷新及新页面读取同源偏好时保留；主题和筛选 URL 不受影响。
- [x] 缺失/无效/不可读或不可写存储均有正确退路；普通访客默认中文。
- [x] 文档语言与选中语言同步；尚未翻译内容继续继承中文语言标记。
- [x] 载入与 404 路由在两种语言下显示对应提示和可用返回操作。
- [x] 现有检查的切换逻辑兼容持久化，相关浏览器回归及 lint/build/performance 通过，证据明确记录来源。
