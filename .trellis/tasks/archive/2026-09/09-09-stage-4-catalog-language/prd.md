# 补齐目录公共界面双语

## Goal

让中英文偏好覆盖知识库与项目目录的公共检索界面，访客切换语言后能理解筛选、结果和阅读操作，并保留正在浏览的位置与条件。

## Requirements

- R1：知识库标题/说明、搜索辅助名称与 placeholder、栏目主次标题、数量/待首发、结果计数、分页和空结果跟随共享语言。
- R2：项目目录标题/说明、三个现有分组、数量和详情操作跟随共享语言；文章阅读操作与辅助名称同步。
- R3：栏目仍同时保留中英文身份，按当前语言排列主次；所有文章/项目标题、摘要、标签、系列和内容保持原值及中文语义。发布入口和原因仍由原 `getPublishedProjectLinks` 投影，保留中文语义，留待共享文案阶段统一处理。
- R4：语言变化不改变 canonical URL、搜索草稿、栏目、分组、页码、历史、卡片身份、阅读返回/焦点或可访问的按钮状态；不重挂载路由或引入第二套语言 state。
- R5：英文在 320/390/430/1440、三主题可读且无裁切；保留原生键盘操作、44px 移动目标、4.5:1 栏目文字对比度及 reduced-motion。
- R6：沿用原循环的本地规划/启动/提交授权；只归档本子任务并实际返回父任务。禁止 push、部署、签名、生产模型、公开发布与保护状态快照写入。

## Acceptance Criteria

- [x] 新语言断言在原 build 上因目录仍是中文而失败，固定负向证据。
- [x] 两类目录公共控件双语、原内容/发布入口中文标记与实际文案一致。
- [x] 语言切换、浏览器历史/刷新/复制链接、输入草稿与阅读返回保持；栏目键盘、双语对比度和移动几何检查通过。
- [x] lint、build、目录确定性合同、analytics、registry、performance、smoke 与当前完整 UI 通过，记录实际检查边界。
- [x] 精确本地提交、验收记录、归档和父任务回切完成。
