# 三主题文字层级与卡片配色

## Goal

让首页与共享导航在晨曦、自然、星辰三个主题下具有清楚、柔和的文字层级：访客先看到标题，再读说明，按需要识别状态和操作；分类色可辨，长标题可读，深色主题没有大面积粗亮文字同时抢占注意力。

本轮用户请求是“规划一下接下来应该怎么做”，后续“继续”延续规划。本任务保持 planning，本轮不实施产品样式。沿用父路线图的本地授权与交付边界。

## Confirmed Facts

- 基线为 `bb771db78d5e419a3a9ea45951fb326a8baff264`，tracked/index 干净，原 13 份未跟踪资料保留；前项轮播运动修复已完成，不能覆盖其生命周期与原生缩放行为。
- 上轮三个主题 × 两种语言的六组浏览器证据见 `baseline.md`。Stellar 卡片标题/说明/按钮为 `#E7EAF1 / #C3C7D6 / #E4FCFF`，字重分别为 `650 / 500 / 700`；Windows 实际标题使用粗体。
- `src/styles/hero-split.css:439` 的轻衬线标题被 `:924` 的首页 UI 字体与 650 字重覆盖；`:902` 的公共 `--card-accent` 覆盖了 `:386` 起的分类色。只在浏览器移除后一声明即可恢复四色。
- `hero-split.css:1205` 起的分类选择器与 `:1387` 的 Stellar 规则优先级不同，导致卡片背景/边框应用不均。当前桌面卡片 86px 高，标题列约 253px，前三项长标题均占两行。
- `src/styles/navigation.css:2` 与 `scripts/check-ui.mjs:1246` 定义并验证桌面 14px/650 字重；调整时必须同步合同，保持跨路由、hover/focus/active 的尺寸稳定。
- 参考站仅有用户截图；没有准确 CSS、字体或可测 URL。新配色属于基于截图与本站证据的设计建议，不声称逐像素复刻。

## Requirements

- R1（P2，覆盖修复）：恢复 signal/preview/commerce/image 的分类强调色；同主题各类卡片使用一致的基础材质、边框规则和独立分类色。整理命中这些元素的覆盖链，不能继续靠追加更高优先级补丁处理。
- R2（P2，文字层级）：分别定义主视觉标题、卡片标题、正文、辅助信息、状态/计数和动作文字的角色，亮度与字重协调。最强强调保留给少量重点；小字达到可读要求，不统一降低祖先 opacity。
- R3（P2，三主题与共享导航）：Stellar 优先校准灰蓝/灰紫层级和常态按钮；Morning/Nature 保留各自色相，按实际背景调整。导航通过共享 token 调整，各路由的五项文字指标及状态几何保持一致。
- R4（P2，内容与空间）：容纳当前真实长中英项目名，完整显示标题、现有说明摘要和动作；使用统一桌面行高与移动端自适应高度，不缩小文字或改写项目名来挤进 86px。保留分类、项目顺序、入口状态、链接及 authored 内容策略。
- R5（验证与交付）：保存同尺寸修改前后截图、真实计算样式、平台字体与背景合成对比度。通过相关确定性 UI、交互与性能检查后，按精确范围本地提交，归档本子任务，再实际回到父路线图。

## Recommended Design Defaults

卡片标题推荐恢复现有轻衬线字体；正文、导航与按钮保留 UI 无衬线。此项已作为可选偏好询问，尚未收到明确选项，故只作为规划默认，不记作用户已选定。具体初稿参数、取舍和收敛方法见 `design.md`；最终色值以真实背景和视觉对照为依据。

## Acceptance Criteria

- [ ] AC1 / R1：三主题均恢复四种语义分类色，同类一致、不同类可辨；主题/语言切换及 hover/focus 后不被公共规则抹平。Stellar 背景/边框规则对四类卡片一致生效。
- [ ] AC2 / R2：普通标题、说明、辅助信息、状态和动作的计算样式符合各自角色；主会话查看三主题前后截图，确认粗亮文字占比降低且阅读顺序清楚。必要文字与现有 Hero/卡片标题的对比度均至少 4.5:1；诗句/小标签不能因调色进一步难读。
- [ ] AC3 / R3：共享导航在 `/`、`/projects`、`/blog`、`/status`、项目详情、博客详情下保持同一文字与 active 几何合同；颜色变化不依赖页面重新加载，状态切换不加粗/缩放文字造成跳动。
- [ ] AC4 / R4：1440 桌面和 320/390/430 窄屏，三主题 × 中英文的 24 组中，真实长标题、说明摘要、动作无重叠或容器裁切；无横向溢出，控件保持 44px 目标，移动首屏仍能看到首张项目卡。
- [ ] AC5 / R4：桌面轮播自动运动、普通滚轮惯性、原生缩放、焦点/悬停暂停、移动/桌面与 reduced-motion 切换保持；数据、动作目标、偏好、URL/history 和 DOM 连续性不变。
- [ ] AC6 / R5：lint/build、相关专项、performance、smoke 与最终一次完整 UI 通过；新鲜浏览器证据及输入版本对应，原断言保留；精确本地提交、当前子任务归档与父回切有实际记录。

## Scope And Constraints

首批交付包括首页 Hero/状态/项目面板与共享导航。其他页面回归共享导航及实际继承受影响 token 的区域；页面自身独立配色的问题须有证据后再进入范围，不预先扩展全站重做。

复用现有字体栈、class-based CSS、三主题来源、Lucide 和 Playwright；保持现有 8px 圆角、布局主结构与背景动效所有者。无需新字体下载、新框架、新 Canvas/RAF 或新增业务功能。只允许与本问题直接相关的样式、必要检查和规范变更。

不修改内容事实、项目名称、authored/SEO 翻译、Flow shader/profile、助手业务、依赖、公开快照 `public/status/blog-semi-synthetic.json`、其他任务与旧 worktree。沿用不 push/deploy/sign、不调用生产 DB/relay/model、不公开内容/启用 Feed/Cron、不操作未知 scheduler 的边界。
