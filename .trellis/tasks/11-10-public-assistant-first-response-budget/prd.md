# 公开助手首响应预算

线上唯一获批请求明确在 `awaiting_headers` 阶段用完 20 秒。继续用离线方式改进预算分配，不发送新真实模型请求、不更换模型或渠道。

验收：

- 首响应等待与已开始流的空闲等待分开；首响应可使用剩余生成预算，流式空闲时限保持现有配置。
- JSON/SSE 路由从接收请求时建立同一个绝对截止时间，认领请求/恢复历史花费的时间不能在 Agent 开始时重新获得。
- 为校验与保存预留最多 5 秒（不超过配置总预算的 20%）；生成、404/405 兼容路径与未来尝试共同受剩余时间限制。
- 保留尝试上限、独立备用保留窗口、用户取消与超时脱敏，预算耗尽不得再发起生成。
- 默认 45 秒总预算和 20 秒流式 idle 配置不变；不修改另一会话的实例档位配置。
- 仅通过本地模拟不能证明供应商会在更长等待内响应；发布和新的真实验收仍需具体授权。
