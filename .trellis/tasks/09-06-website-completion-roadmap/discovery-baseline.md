## 复现步骤

### 博客

1. 打开 `/blog`，选择 Project Notes 栏目，搜索 `RAG`，确认显示 2 张文章卡片。
2. 点击首张卡片的阅读按钮，等待文章详情及返回链接显示。
3. 使用浏览器后退，或点击详情页的“知识库”返回链接。
4. 栏目恢复 `all`、搜索恢复空字符串，文章卡片变成 11 张；选择和搜索前后的目录 URL 都是 `/blog`。

### 移动项目集

1. 在 `320/390/430px` 打开 `/projects`，展开“工具”分组。
2. 点击该分组首个项目的“查看详情”，等待详情及返回链接显示。
3. 使用浏览器后退，或点击详情页的“项目集”返回链接。
4. `aria-expanded="true"` 从 `project-group-panel-tool` 对应的按钮变为 `project-group-panel-ai` 对应的按钮。

## 代码依据

- `src/pages/BlogPage.tsx:15`：栏目、搜索、页码初始化为页面内 `useState('all' / '' / 1)`；`onReadMore` 只导航到文章路径，没有保存返回上下文。
- `src/pages/BlogPostPage.tsx:91`：返回链接固定为 `/blog`。
- `src/pages/ProjectsPage.tsx:12`：移动分组初始化为 `ai`；`openProjectDetail` 只导航到项目路径。
- `src/pages/ProjectDetailPage.tsx:114`：返回链接固定为 `/projects`。

页面卸载后局部状态消失，而目录 URL 和详情返回链接都不携带条件。无需改变公开文章或项目数据即可处理这一交互问题。
