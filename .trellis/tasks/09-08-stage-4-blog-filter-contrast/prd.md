# 修复博客栏目文字对比度

## Goal

让仍可点击、可键盘选择的博客栏目文字在三主题下保持可读，包括中英文栏目身份、篇数与“待首发”状态。

## Requirements

- R1：桌面栏目标题和副标题在 721/1440、Morning/Nature/Stellar 下达到至少 4.5:1 的文字对比度；包括正常、空栏目、选中和 hover 状态。
- R2：复用现有主题文字/实色背景令牌，去掉降低可读性的透明叠加；筛选栏背景隔离页面动态深浅变化。保留原有布局、字号、颜色主题、按钮分组/pressed 语义、键盘顺序、移动 select、栏目计数和待首发文案。
- R3：在既有博客专项中加入真实浏览器对比度检查：取得实际颜色/透明度，暂时隐藏文字但保留布局，从截图的文字区域背景采样，再恢复 DOM。检查必须先在旧 CSS 上失败，不能只比较变量名或忽略 opacity。
- Owned：src/styles/catalog-pages.css 的博客栏目文字及筛选栏背景规则、scripts/check-blog-discovery-ui.mjs、相关组件规范、本子任务和父任务记录。
- Forbidden：业务 TSX、URL/筛选逻辑、公开数据、文案、其他 CSS、server/、public/、依赖/lockfile、生产/模型请求与发布。
- 验证：lint/build、博客合同、博客专项、smoke、完整 UI、performance、git diff --check。API 只使用本地 fixture。

## Acceptance Criteria

- [x] 主会话只读基线覆盖 6 个宽度/主题场景、72 个文字样本；42 个低于 4.5:1，空栏目副标题 1.77-2.14:1，控件 disabled=false。
- [x] 新回归已在未修复 CSS 上实际失败（721/Morning/All Notes 为 2.86:1）；修复后所有栏目、空栏目、选中/hover 和原生键盘行为通过。
- [x] 原有 24 组浏览路径和 6 组语义/断点检查、smoke、完整 UI 与必要静态门禁通过，保存源码/构建/日志证据。
- [ ] 精确本地提交，仅归档本子任务并实际返回父任务，继续评估剩余本地合同。

## Notes

- 这是限定在现有栏目控件的 CSS 修复，采用 PRD-only 小任务。已有父任务持续授权覆盖规划、启动与本地提交，由主会话直接实施/验证。
- 回滚单位为本子任务的独立提交。不得通过 disabled、隐藏栏目、减小字号或删减待首发文案来回避可读性问题。
