# 修复设计

2026-11-05 续作：项目目录咨询使用从 portfolio 与 publication 策略生成的独立、只读目录投影。按完整条目打包为最多 8 份、每份不超过 900 字符的站内证据，覆盖公开入口、登录门禁、展示页与案例规划；不扩大普通语义检索或引用协议上限。目录读取在 Public 服务本地完成，不经过远端 embedding/reranker，也不改已同步的向量资产。无法读取目录时保持原检索降级行为，不能将 partial 强改 answered。真实默认 Agent/RAG 路径以夹具证明覆盖，普通项目细节仍走已有远端 RAG。刷新恢复通过真实页面 reload、原会话与 Revision 验证，夹具不得在每次导航时清空存储。生产模型、DNS/证书改动与公开发布留待本地候选验证完成后按已有门禁处理。

1. 为明确本站范围提供确定性路由；显式 site/web 模式仍优先，外部比较仍允许 combined。
2. 本站降级按证据标题和摘要分条展示，保留引用来源与 degraded 元数据。
3. 前端共享可清理的绝对截止时间，覆盖 fetch、正文读取及 SSE；调用者取消仍是 AbortError，超时单独映射。
4. 健康检查仍最多两次，无后台保活；过期不撤销当前文档已确认的可用状态，下一次打开显式重新检查。
5. 不解除持久化恢复/分支门禁；超时走已有重试或新会话出口。

历史证据：10 月浏览器 GET 两个公开入口 health 均 200/configured；Node TLS 失败不作为线上不可用结论。11 月用户已确认 My Workspace，已读取服务、部署、低敏配置摘要和启动日志，最新事实见执行记录。

生产构建回归补充了两项约束：会话初始化读取必须没有存储写入副作用，首次持久化在挂载 effect 中完成；反馈、取消、删除的成功响应需要在 deadline 内消费正文，避免取消未读正文后浏览器缺少响应完成事件。SSE 仍按应用层终态帧完成，不等待 HTTP EOF。

11 月监测修正：健康接口返回 HTML 或 405 只说明响应合同不符，不能单独证明 Pages Functions 未部署。应分别核对平台 uses_functions、部署版本、上游就绪和边缘路由；不据此删除 SPA fallback。

2026-11-05 文本渠道切换复用现有 Responses 流式适配器、JSON 提示词与引用验证，不改问答流程。候选从用户授权的新渠道目录选择，使用公开证据验证 `gpt-6-luna`；保留 `PUBLIC_ASSISTANT_MODEL_MAX_ATTEMPTS=1`、schema mode=off、45 秒总截止和 20 秒生成流空闲截止。旧配置加密恢复，非目标变量摘要前后比对；平台更新已触发部署时只观察，不重复发起。部署后以新的有限业务验证核对生成、引用、恢复与测试会话清理。
