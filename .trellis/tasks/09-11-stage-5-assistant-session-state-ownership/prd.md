# 公开助手异步会话状态归属

## Goal

让独立异步操作合并到最新会话注册表，并让被手动操作接替的初次恢复在失败后进入可见、可重试的终态，避免已删除会话标识回写和无请求的持续加载。

## Requirements

- R1：成功删除非当前会话后，独立当前生成无论先后完成，都不得从旧闭包恢复已删除 capability；失败删除保留其 capability 和草稿，独立生成只完成一次且不被取消。
- R2：未就绪的当前会话恢复被手动恢复取代后，手动操作失败必须结束无主 loading，保留当前身份/草稿，显示现有恢复错误界面；非当前目标过期只移除该目标。未取得当前权威历史时仍禁止发问。
- R3：从该错误状态可明确重试当前会话或新建会话；旧初次响应不能覆盖新请求、错误状态或成功的目标历史。不自动重试恢复或排队发问。
- R4：已就绪会话的既有历史操作、当前过期自愈、历史/分支/图片门禁与问题编辑重发保持；API、registry 存储格式与纯 helper 语义不变。
- R5：将回归加入现有历史检查，四个代表配置覆盖两个成功到达顺序、失败删除、打断恢复的失败/过期/成功及两种显式恢复选择；保留旧构建负向证据，完成基础、助手合同、相关专项、smoke 和完整 UI。
- R6：初次恢复的错误提示不能声称已收到回答或当前仍可提问；复用既有恢复失败文案，保留限流退避。桌面与手机提示文字、两个恢复按钮完整可见且不重叠。
