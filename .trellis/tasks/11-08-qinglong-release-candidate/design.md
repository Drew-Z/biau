# 设计

本次复用既有组件、活动适配器及共享运行时，不另建播放或事件状态机。源码导出来自固定提交，覆盖清单仅包含 PublicAssistantPet、对应 CSS、桌宠专项、已有青珑说明及九份角色资源。

验证中修复两个已有测试入口：阅读链接测试等待目录实际对齐后记录基线；AI 日报测试支持显式回环 preview，以验证已构建的生产开关候选，默认仍可启动其既有开发服务器。两处均不改变网页产品代码。

依赖按冻结的 package-lock 安装在任务临时目录。构建、预览与浏览器检查全部指向该目录，外部网络由既有夹具阻断。正式保留源码包、输入/输出哈希和验证证据；依赖与临时服务在收尾清理。

发布前须比较远端和当前基线，重新核对部署环境开关及已有线上版本。若主线推进，逐项核对前端、公开资源、Functions、构建配置和依赖：有影响时重新构建与验证；输入完全相同时保留哈希证据并复用已完成检查。本次通过 Git 推送让 Pages 构建最新提交，不能上传旧全站构建覆盖新发布。回退先验证旧角色资源仍可加载，线上回退使用发布前的确切部署版本并恢复新版本；检测到并发部署时停止切换，不能把本地模拟冒充线上演练。
