# 首页单主题视觉架构重构

## Goal

在保留主站品牌、核心信息、导航、路由、项目内容、CTA 与无障碍能力的前提下，重构全站共享视觉架构，使所有路由使用同一套接近参考站默认 Stellar 场景的流体背景与克制星场，并以首页作为参考站视觉对齐的主要验收页。消除当前多主题叠层、固定线条、静态点阵和重复伪元素造成的构图干扰，让视觉相似度由稳定的单一背景系统保证，而不是继续叠加局部补丁。

## Background

- 当前全站共享 Dusk、Garden、Stellar 三种场景及 light/dark 组合，首页还叠加背景、星场、基础纹理、Stellar 特效和组件伪元素。
- 已确认参考站默认 Stellar 背景的主色构图为 `linear-gradient(122deg, #59575c 0%, #2b315f 30%, #354b7b 47%, #092243 70%, #052433 100%)`；目标是复刻其视觉语言，不复制参考站私有脚本、品牌、字体、音效或外部资源。
- 本任务是结构性收敛，不再以微调六套视觉组合为主要手段。

## Requirements

- R1：全站背景只保留一套 Stellar 视觉 profile；移除 Dusk、Garden 场景以及场景切换入口和相关状态分支。
- R2：背景构图仅由流体背景与星场两个明确 owner 负责；其他层不得重复绘制全局渐变、星点或固定纹理。
- R3：删除或重写不属于参考站构图的固定线条、静态点阵、landmark、基础纹理和冗余组件伪元素。
- R4：Stellar edge/perimeter 只保留在参考站确有对应强调的位置，不得作为所有容器的通用装饰。
- R5：保留主站品牌和主要内容，包括导航、既有路由、首页关键信息、项目卡片、CTA 与无障碍语义。
- R6：保留现有技术栈与 class-based CSS、设计令牌和 Lucide 图标，不引入第二套 UI 框架。
- R7：视觉实现应支持合理性能降级，且降级结果仍保持同一 Stellar 构图，不切换成另一主题。
- R8：重构必须避开用户现有的 `public/status/blog-semi-synthetic.json` 未提交修改。

## Acceptance Criteria

- [ ] 全站不再提供 Dusk、Garden 或其他背景场景切换，任意路由、入口与刷新路径均呈现同一 Stellar 背景构图。
- [ ] DOM/CSS/WebGL 视觉层中不存在重复的全局星点、固定网格/线条、landmark 或无归属的全屏装饰层。
- [ ] 流体背景与星场的职责、层级和性能降级边界在实现中可明确定位。
- [ ] 主要内容、导航、路由、项目卡片、CTA、键盘操作和 reduced-motion 行为保持可用。
- [ ] `light` / `dark` / `auto` 仅改变文字、面板与控件可读性；背景 stop、流体方向、星点密度和全局构图均保持不变。
- [ ] 关键桌面与移动视口的截图审计显示：主色分布、流体运动、星点密度、内容层级和留白接近参考站默认 Stellar 场景。
- [ ] `npm run lint`、`npm run build` 及相关 UI 检查通过。

## Out of Scope

- 复制参考站 Logo、站名、私有字体、音效、私有脚本或外部托管资源。
- 改写主站业务信息、项目数据、内容路由或引入后端/CMS。
- 为 Dusk、Garden 或六种 scene × appearance 组合继续做兼容性调参。

## Appearance Decision

- 保留 `light` / `dark` / `auto` 外观入口。
- 外观模式只控制文字、卡片、面板、导航和控件的可读性与表面处理。
- Flow、星场、首帧背景、全局色彩构图和 Stellar 视觉 profile 固定不随外观模式变化。
- 场景入口不再循环切换 Dusk/Garden/Stellar；品牌 Logo 交互保留为普通首页入口或无副作用按钮，并移除场景相关提示。
