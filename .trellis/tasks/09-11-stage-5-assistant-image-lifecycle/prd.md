# 公开助手图片处理与会话隔离

## Goal

避免读者选图后新建或切换会话时，旧图片或处理错误进入新的输入区；图片就绪前，键盘与按钮必须使用一致的发送门禁。

## Requirements

- R1：新建会话、成功恢复/切换会话、删除当前会话、当前会话过期导致 ID 变化以及移除图片后，旧图片处理的成功、失败和收尾均不能覆盖当前输入状态。会话 ID 的统一提交入口也必须同步重置图片，不能仅依靠几个显式操作的清空路径。
- R2：旧处理失效后可以立即选择新图；旧回调不能提前结束新图的处理中状态或清空新选择的文件输入。
- R3：图片准备期间按 Enter 不发送请求、不丢失文字；准备完成后，显式发送携带选定图片。继续保留 Shift+Enter 换行和输入法组合输入保护。
- R4：当前图片处理失败仍显示既有错误，处理后可以重新选图；图片继续仅在内存中，不进入历史或浏览器持久化。
- R5：保持已有压缩、大小限制、复制、恢复、引用、分支/修订和语言合同；不引入新依赖或修改后端协议。
- R6：完整 UI 暴露的阅读延迟夹具时序问题只修正检查同步：限定时间内等待真实文章模块拦截，并保留释放前内容未加载以及完成/交互/离开后的原断言；不改变阅读业务代码。
